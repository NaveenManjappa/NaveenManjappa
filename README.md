### 🚀 Featured project: [HR Assist](https://github.com/NaveenManjappa/hr-assist)

An enterprise-style RAG assistant that answers HR policy questions with citations to the exact document, version, section and page. **[Try the live demo →](https://hr-assist.naveenmanjappa.com)**

- **Typed, guarded replies:** every reply is a cited Answer, a Clarification, an Abstention or a privacy Refusal. It is tested against prompt injection and protected by rate limits, token caps and a spending limit.
- **Version-aware answers:** it works out the date a question applies to and answers from the policy version in force at that time.
- **Evaluation:** 125 questions with gold answers, measuring retrieval hit@k, reciprocal rank, groundedness and response type.
- **Engineering:** pytest, strict mypy, ruff and Vitest in CI. Every merge to `main` deploys to Google Cloud Run and is smoke-tested through the public URL.
- **Agentic delivery:** four ADRs record the key decisions. The work was split into 34 GitHub issues and built with Claude Code as the main coding agent.

`Python` · `FastAPI` · `LangChain` · `Qdrant` · `OpenAI` · `Angular` · `Tailwind` · `Cloud Run` · `Firebase Hosting` · `GitHub Actions`
